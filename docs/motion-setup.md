# Product Motion: окружение проекта

Скилл находится в `.agents/skills/product-motion/`. Его файлы полностью совпадают с
`product-motion` из https://github.com/dyachkovp/agent-skills/tree/main/product-motion
на момент проверки 23 ноября 2026 года. `SKILL.md` прочитан полностью.

Лицензия исходного каталога сохранена в [product-motion-LICENSE.txt](product-motion-LICENSE.txt); лицензии шрифтов находятся рядом с файлами шрифтов.

## Возможности и входные данные

Скилл собирает короткие обучающие и промо-ролики: интерфейс в кадре, движения
курсора, набор текста, камера, титры, музыка и озвучка. Экспортирует MP4 в 16:9
и 9:16, с субтитрами и без них. Экраны и надписи берёт из текущего проекта,
а цвета, шрифты и логотипы — из его бренд-профиля.

Для начала нужны фича или сценарий, цель ролика и аудитория, длительность, язык и
формат. Для нашей задачи исходным материалом служат мобильная главная и её сценарий
в коде проекта. Для финальной озвучки нужен аудиофайл: скилл готовит текст и промт
для Gemini TTS, пользователь присылает готовую запись. Музыку можно предоставить
отдельным файлом или начать с черновой.

## Запуск инструментов

Из корня репозитория:

```sh
source .agents/motion-env.sh
python .agents/skills/product-motion/scripts/check_env.py
```

В `.agents/tools/` подготовлены Python-окружение с Playwright, NumPy, SciPy и
Pillow, Chromium для Playwright, а также нативные ffmpeg/ffprobe для Apple Silicon.
Активация действует только в текущем терминале. Каталог инструментов исключён из
Git; для новой машины окружение нужно подготовить заново по `SKILL.md`.

ffmpeg и ffprobe скачаны с https://www.osxexperts.net/ . Проверенные SHA-256
исполняемых файлов:

- ffmpeg: `f3cc9de031a39020b7285a62667b951949a0377483b7cbf708c7126234fda34f`;
- ffprobe: `a663dbfafcd144f441834bc4af50077ccb969b635775612e5eddb6574f2caed0`.

Chromium установлен. Запуск браузера из текущей ограниченной среды останавливается
ошибкой системного разрешения `bootstrap_check_in ... Permission denied`.
Проверку его запуска нужно повторить командой выше в обычном терминале macOS.
Повторная установка браузера эту ошибку разрешений не исправит.

Для первого ролика найден рабочий способ в Codex: встроенный браузер открывает HTML-сцену со штатным engine.js, а поле времени позволяет покадрово получить те же render(t). Затем ffmpeg собирает MP4. Так успешно собран и проверен 15-секундный ролик home-promo; подробности — в motion/home-promo/README.md.

`faster-whisper` понадобится для выравнивания готовой озвучки, а фильтр rubberband —
только для ускоренной версии ролика. Эти необязательные возможности не входят
в базовую проверку рендера.
